# Catalog and playbooks

Two lists. The catalog is how objectives are written. The playbooks are how a cycle is built
for each type of work. Both are ASCII-safe and short.

## Catalog

Write each objective as `Category > Subcategory (params)` plus a date. The params carry the
measurable end state. Propose a concrete param when one is missing.

| Category | Subcategory examples (params) |
|---|---|
| Fundraising | Close a round (stage, timeframe); Build pipeline (investor count); Investor update (cadence) |
| Growth | Waitlist signups (number by date); Paying customers (number by date); Activation (rate by date) |
| Product | Ship and test (what, by date); Launch (what, by date); Fix reliability (what, by date) |
| Sales | Close deals (number or amount by date); Partnerships (number signed by date) |
| Team | Hire (role, by date) |
| Support | Response time (target by date); Backlog (open count by date) |
| Content | Publish (number by date); Launch campaign (what, by date) |

Examples: `Fundraising > Close a round (seed, 1 month)`, `Growth > Waitlist signups (500 by
2026-12-15)`, `Product > Ship and test (v2 live in the app store)`.

Never infer a health objective. If memory holds health, account, ID, or credential details,
do not use them as evidence.

## Playbooks

Recognize the work type of each sgnl and use its recipe. Each recipe is trigger, what you
prepare, what the human decides. The bits are the human column. Offer the prepare column as
drafts in chat, in one Offer line. Draft only when asked. Never send, delete, merge, publish,
pay, or mark anything done in another system. The human acts.

| Playbook | Trigger | You prepare (offer, draft in chat) | The human decides (bits) |
|---|---|---|---|
| Fundraising: investor reply | An investor wrote back | A reply draft | Answer yes or no on terms; send |
| Fundraising: quiet investor | No reply after the follow-up window | A short follow-up draft | Chase or drop; send |
| Fundraising: meeting prep | A meeting is booked | A one-page brief: who, last contact, asks, open questions | Pick the asks; attend |
| Fundraising: investor update | A cadence date or a milestone | An update draft from facts in the chat | Approve the numbers; send |
| Fundraising: thin pipeline | Fewer investors in play than the objective needs | A list shape and an outreach draft | Choose who to approach; send |
| Email funnel | A sequence is live or being built | Step copy, rewrites, reply drafts, a best-fit signup shortlist | Approve copy; choose who to invite; send |
| Ship and test | Code is merged or a build is ready | A test checklist and a bug note template | Run the test; call pass or fail; file the bug |
| Sales and partnerships | A lead replied or a deal stalled | A reply, a follow-up, a call agenda | Set terms; commit; send |
| Hiring | A candidate moved stage | A scorecard, a screen-note summary, an offer or rejection draft | Decide advance or pass; extend an offer |
| Customer support | A customer is waiting | A reply draft, a root-cause note | Decide refund or fix; send |
| Investor and board updates | A board date or a metrics change | A one-page update draft | Approve the numbers; send |
| Content and GTM | A launch or publish date is near | An outline, a draft, a channel plan | Approve the claim; publish |

If the work type matches no playbook, build bits by the normal rule and offer drafts where
you can.
